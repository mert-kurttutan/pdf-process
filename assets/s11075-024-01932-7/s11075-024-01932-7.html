Abstract

The square root is one of the most used functions in many different engineering and scientific applications. We propose new methods for calculating the square root function that are based on the Newton–Raphson method with Heron iteration. A modification of Heron’s formula combined with an improved selection of the magic constants enables a significant reduction of the maximum relative error (MRE). Simple modifications to the Newton–Raphson formula and the magic number method enable implementation on platforms with limited hardware resources, such as microcontrollers and FPGAs, with variable accuracy. Implementations of new approximation algorithms in the C programming language were carefully tested and evaluated against their software and hardware counterparts on the most popular platforms, e.g., CPUs from Intel, AMD and ARM, GPU from Nvidia and IPU from Graphcore. The proposed numerical algorithms are shown to be superior in terms of computational time, the number of clock cycles, accuracy, MRE, and root mean square deviation.

1 Introduction

Computing the square root and other elementary functions are highly useful in various fields of science and engineering. Arithmetic operations are essential for high-performance computing (HPC), artificial intelligence (AI) including deep neural networks (DNN), digital signal processing (DSP), and in various scientific computing simulations and experiments, such as the Large Hadron Collider (LHC), where 25% of the simulation time was found to be spent in computing elementary functions (cf. [40]).

The basic methods for calculating the square root date back to ancient times. In this article we investigate the classical Newton–Raphson method [17] combined with the famous Heron formula for computing the square root function y = \sqrt{x} for a floating-point argument x :

y_{n+1} = 0.5 \cdot (y_n + x/y_n) \quad (1)

This formula is an essential iterative step in a method invented by Heron of Alexandria, which starts with an initial approximation of y_0 (the seed), and repeats iteration (1) until the required accuracy is obtained. It is obvious that the computational effort of this method depends on the value of the seed, which should be as close to \sqrt{x} as possible.

The main disadvantage of the Heron formula is the presence of the division operation, which has traditionally been considered complex, costly, and slow. However, given the advances in computer arithmetic (software and hardware components), the application of division operation in numerical computations should be re-examined in order to check whether we still need to avoid division in each iteration and rely exclusively on multiplications and additions.

We can think of multiplication as multiple additions and division as multiple subtractions. The difference between the two operations is that the additions in multiplication can be done in parallel, while division is inherently sequential: subsequent subtraction operations are preceded by comparisons. Thus, the hardware multiplier may exploit the inherent parallelism present in the multiplication operation by computing and summing up many subproducts simultaneously, at the cost of an increased die area, while the division operation does not have this feature.

If we take into consideration the first Pentium or Pentium MMX, then the floating point division operation was usually 8–13 times slower than addition or multiplication [18–21]. Moreover, hardware dividers were never pipelined, as that requires replicating a lot of circuitry instead of iterating on the same multiplier module [10]. Nevertheless, a lot of effort in the field of computer arithmetic has already been spent on simplifying or minimizing the number of operations that must be performed, including the

simplification of division. Furthermore, a wider usage of CPU pipelines with a higher instruction per cycle (IPC) factor shrinks the processor cycle gap and finally decreases the number of cycles needed for the completion of simple operations. Therefore, if the division operation is essential, it makes sense to add specialized hardware dividers. By now, specialized dividing circuits have become standard [44].

New generations of processors, such as the Intel Xeon Skylake, dramatically improve these scenarios. If we consider the worst case of addition or multiplication and the best case of division, we see the execution of single operations versus ‘pipelined throughput’. In this case, it’s 4–5 cycles for division operations versus one cycle for addition or multiplication [18]. So, we end up with a 4–5 times slower division versus addition or multiplication. Such a performance difference seems to be a significant improvement, and drastically increases the attractiveness of using division operations, especially when compared to the standard case [18, 21].

Taking into account this discussion, the Heron formula with division operations is still technically sound. It can be found in recent publications and it is a part of commercially used software. For instance, in the CMSIS DSP Software Library ([12] for STM32 microcontrollers) the way of computing the square root function is the classical Heron formula. The square root was also implemented in FPGA [4, 9, 10]. Therefore, further development of the theory of the Newton–Raphson method for computing the square root function is the subject of our research reported in the present article.

The contents of the rest of this article are as follows. Section 2 contains a survey of the research related to this paper’s topic. In Section 3, known approaches for computing the square root function are discussed. Two popular algorithms from the literature, referred to later in this paper, are recalled. In the next section, we present several new variants of algorithms as well as their characteristics in terms of accuracy (number of correct bits) and maximum and minimum relative errors. The conclusions from these research results are presented in the last section.

2 Survey of the literature

Investigation of Heron formula has a long and distinguished history which can be traced in the vast literature on this topic: [2–6, 9–14, 16, 23, 25–27, 30–33, 37–39].

Modern methods for computing of square root include:

  • • direct look-up table and bipartite tables [1, 5, 30] - the method is good for low precision computations;
  • • digit recurrence methods [8] - these methods have linear convergence, but are rather slow;
  • • low-degree polynomial or rational approximations [1, 10, 22] - this method needs division and many add and multiply operations;
  • • multiplication-based methods: Newton–Raphson, Goldschmidt and Taylor algorithms [17, 26, 30, 43] - the algorithms include a seed generator (for instance LUT table), although they have quadratic convergence require many integer or floating-point (FP) arithmetic operations;
  • • methods that include multiplication-based magic constants (fast inverse square root) as initial guess and Newton–Raphson iterations and require many FP arithmetic operations [24, 28, 32–36, 39, 41];
  • • digit by digit, CORDIC method [5, 17, 30] - has linear convergence and is slow;
  • • a two-variable iterative method [15] - requires many arithmetic operations;

Several simulation approaches for choosing initial approximations of the seed (choosing an initial guess) were presented in [2, 27, 37]. An overview of this method can be found in [2, 11, 30, 37].

Surveys of floating-point arithmetic methods can be found in [7, 38].

3 Previous approximation algorithms

We know that the classical iterative method is Heron's rule, based upon the formula f(y) = y^2 - x , so that f(\sqrt{x}) = 0 . The iteration applied in Newton–Raphson method is either

y_{n+1} = y_n - \frac{y_n}{f'(y_n)} = y_n - \frac{y_n^2 - x}{2 \cdot y_n}

or (1), which converges quadratically. Each iteration (1) costs one division operation, one addition, and one multiplication by 0.5.

Let us notice, that in practice, due to division operation, Heron formula is often replaced by a simpler multiplication-based Newton–Raphson formula (2) for computing the reciprocal square root:

y_{n+1} = 0.5 \cdot y_n \cdot (3 - x \cdot y_n \cdot y_n) \quad (2)

which contains only four multiplication operations and one subtraction, and enables easy way to obtain the square root function [1, 5, 21, 24, 26, 28, 29, 33–36, 38, 42].

Let us give a simple solution of iterative Heron formula (1) for initial approximation of y_0 in the closed form

y_n = \sqrt{x} \frac{(y_0 + \sqrt{x})^{2^n} + (y_0 - \sqrt{x})^{2^n}}{(y_0 + \sqrt{x})^{2^n} - (y_0 - \sqrt{x})^{2^n}}

Then, the current relative error equals

\delta_n = \frac{2 \cdot (y_0 - \sqrt{x})^{2^n}}{(y_0 + \sqrt{x})^{2^n} - (y_0 - \sqrt{x})^{2^n}}

Such a representation of formula (1), when the iteration number n is high, e.g. n = 12 [3, 4], enable time savings for computing of exact results and errors, which can reach sufficiently large values. Moreover, the formulas allow selection of the best initial approximation (constant, linear, quadratic, ...) in terms of the absolute error or the relative error for any iteration of Heron formula in the selected argument range. For example, if for initial approximation the value y_0 = 0.5x is selected (cf. [12]) then the relative error of each iteration equals:

\delta_n = \frac{2 \cdot (0.5x - \sqrt{x})^{2^n}}{(0.5x + \sqrt{x})^{2^n} - (0.5x - \sqrt{x})^{2^n}} \quad (3)

Figure 1 shows the chart of the relative error \delta_n(x) of the Heron method (1), according to formula (3), for n = 1 and x \in [1, 16] . As one can see, the function \delta_n(x) is nonlinear within the argument range [1, 16] . The function is decreasing to 0 with x within the range [1, 4] . Then, it is increasing within the range [4, 16] . Therefore, in our opinion the best initial approximation of square root function for FP numbers is obtained by using so called magic numbers as it was proposed in [6, 16, 23, 39]. In particular, in [6] and [16] the Algorithm 1 was given for the initial approximation of FP square root. In comparison to the function depicted in Fig. 1 the function code of Algorithm 1 gives a still rough, but much more accurate initial square root approximation (MRE is about 0.06 for all normalized FP numbers).

4 New approach and algorithms

In our new approach to the application of Heron formula in conjunction with magic numbers we propose two significant improvements. To begin with, we propose a modification of the Heron formula

y_{n+1} = k_n \cdot (y_n + x/y_n), \quad (4)

where k_n - is a constant coefficient close to 0.5. This alteration provides an alignment of the maximal values of the positive and negative errors with respect to zero in each iteration. This trick may be used in conjunction with an improved selection of the magic constants in order to construct the initial approximation, which constitutes the second improvement. We will now explain the last issue in detail.

Recall, after [32], the basic theory and results related to the reciprocal square root approximation. It is known that the behaviour of the relative error in calculating y_0

over the whole range of normalized FP numbers can be described by its behaviour for x \in [1, 4] [5, 30, 38]. In this range there are three piecewise linear approximations of the function y_0 = \{y_{01}, y_{02}, y_{03}\} :

y_{01} = \frac{t}{2N_m} + \frac{1}{4}x + \frac{1}{2} - \frac{1}{4N_m}, x \in [1, t), \quad (5)

y_{02} = \frac{t}{N_m} + \frac{1}{2}x - \frac{1}{2N_m}, x \in [t, 2), \quad (6)

y_{03} = \frac{t}{N_m} + \frac{1}{4}x + \frac{1}{2} - \frac{1}{2N_m}, x \in [2, 4), \quad (7)

where

t = 2 - 2m_R + N_m^{-1} ; m_R = N_m^{-1}R - \lfloor N_m^{-1}R \rfloor , m_R > 0 – is the fractional part of the mantissa of the magic constant R ;

N_m – is the floating point precision of computations.

In order to find the optimal value of the magic constant from the point of view of minimizing the relative error of the initial approximation y_0 , consider the following maxima of relative errors \delta_0 = \{\delta_{01}, \delta_{02}, \delta_{03}\} :

\delta_{01} = y_{01}/\sqrt{x} - 1, \quad (8)

\delta_{02} = y_{02}/\sqrt{x} - 1, \quad (9)

\delta_{03} = y_{03}/\sqrt{x} - 1, \quad (10)

at the points x_{min} = t , for y_{01} ; x_{max} = 2 , for y_{02} or y_{03} . Applying the method of [33], we find that the value m_R = 0.463353872483829593509611 is minimal for N_m = 8388608 (single precision). From this, we obtain R_{0min} = 0x1fbb4f2e (532369198), which only differs slightly from that given in [39], 0x1fbb4ecc (532369100), see the code for FP float in Sqrt_Heron-Muller, and gives almost the same MREs for the Heron formula in the first and the second iterations:

\delta_{1min} = -5.069e - 8; \delta_{1max} = -6.245e - 4; \text{ (with 10.64 correct bits)}

\delta_{2min} = -1.1917e - 7; \delta_{2max} = 2.534e - 7; \text{ (with 21.91 correct bits)}

We will continue to use this magic constant, 0x1fbb4f2e , in the corresponding algorithm Sqrt_Blinn_Modified (available from our GitHub site). However, it is known from [2, 27, 30, 37] that for each iteration the optimal values of the relative error hold only for their initial approximations. This approach has been used to improve the method developed by [37]. Hence, the optimal initial approximation for the first iteration according to the classical Heron formula and the modified Heron code Sqrt_Modified_Heron_1 (available from our project repository on GitHub) has the same form as the Sqrt_Heron-Muller algorithm, only with a new magic constant. In this case, it is an improved magic constant 0x1fbb67af . Below we will provide insight into its detailed computation.

Modifying the Heron formula by changing the value of k_n makes it possible to significantly reduce the error of calculating the square root, especially when performing several Heron iterations. The influence of the value of k_n is stronger than the previously proposed approaches to reducing errors, such as an optimal choice of the initial approximation [2, 27, 30, 37]. For example, the new algorithm with one magic constant and a modified Heron formula (4) for the first iteration achieves much better properties of the relative error:

y_1 = k_0 * (y_0 + x/y_0). \quad (11)

Again, in this case we have to find an optimal value of the magic constant R_{1\min} , but from now on, together with the optimal value of the coefficient k_0 . For this purpose we shall list the general formulas for the relative errors in the three segments of the initial approximation y_0 , similarly to (8)–(10), but after iteration (11), substituting there (5)–(7), respectively:

\delta_{11} = y_{11}/\sqrt{x} - 1;

\delta_{12} = y_{12}/\sqrt{x} - 1;

\delta_{13} = y_{13}/\sqrt{x} - 1,

where

y_{1i} = k_0 * (y_{0i} + x/y_{0i}), i = 1, 2, 3.

Note that the coefficient k_0 in the Heron formula remains unchanged for all segments. Based on the maximum points, the values of the positive, negative relative errors and the contact points (connecting segments), the values of the respective coefficients k_0 and m_R were calculated using the serial approximation method described in [33]. As a result we obtain the following values:

\begin{aligned}m_R &= 0.4641016747423993624451768, R_{1\min} = 0x1fbb67af, \\ k_0 &= 0.49984979429967059464765.\end{aligned}

The magic constant remained the same as previously, but a significant reduction of the error can be obtained by modifying the Heron formula. The code of the corresponding Algorithm 3 with two iterations is as follows.

Algorithm 3 SQRT_Modified_Heron_2 . 

float SQRT_Modified_Heron_2(float x)
{ float y ;
  int i = *(int*) & x ;
  i = 0x1fbb67af + (i >> 1) ;
  y = *(float*) & i ;

As shown in Fig. 2, the second modified algorithm guarantees approximately half of the MREs, which are roughly symmetrical with respect to zero. It can be theoretically proven that for the classical Heron formula (1), the relation between the MRE of the initial approximation \delta_{0\max} and the MRE for the n th iteration \delta_{n\max} is described by

\delta_{n\max} = \frac{\delta_{0\max}^{2^n}}{2^{2^n} - 1};

and for our formula (4) with the same initial approximation,

\delta_{n\max} = \frac{\delta_{0\max}^{2^n}}{2^{2^{n+1}} - 2};

For n = 1 , the error is reduced by one-half, for n = 2 , to one-eighth, for n = 3 , by a factor of 128. However, in practice, such a reduction cannot always be achieved due to the limited number of bits of the mantissa and the impossibility of establishing the exact theoretical value of the coefficient k_n from formula (4) at the last iteration (therefore, it often has to be given in the rounded form of 0.5). However, the transition to a format with a larger number of bits in the mantissa (for example, from single to double precision) confirms the correctness of the theory. In our paper, we do not use algorithms like Halley or Householder [5, 11], because they are more complicated and slower when compared to the Heron formula due to the additional operations in the denominator and numerator (Halley). We try to improve the initial approximation so as to reduce the number of Heron iterations. Such an approach to designing algorithms for the square root function consists of the following steps. The whole range [1, 4) is divided into two segments [1, 2) and [2, 4) (cf. [1, 10, 30]). Then, for each segment, we find magic constants which minimize the MREs in the first iteration. Simultaneously, there is a need for one more multiplication operation in order to ensure minimal values of the errors of the piecewise linear initial approximations obtained by means of the magic constants – the corresponding code of Algorithm 5 is called Sqrt_Heron_2-segments.

If the idea of further partitioning of segments into subsegments is implemented, we can significantly increase the accuracy of the square root approximation. For instance, we can divide segments [1, 2) and [2, 4) into the same even number of subsegments. Our solution comes from partitioning the first mantissa segment into 2^k , k \in \{1, 2, 3, 4, 5, \dots\} , equal subsegments p : [a, b) , where a = 2^{(j-1)} , b = 2^j , for p \in \{2, 4, 8, 16, 32, \dots\} , and j = \{1, \dots, p\} . The second segment [2, 4) is divided similarly, but the ends of the ranges p : [a, b) are a = 2 * 2^{(j-1)} , b = 2 * 2^j . Next, for all created subsegments, magic constants must be found.

It should be noted that the code of SQRT_16-segments is straightforward, fast, and provides an accuracy of about 12.15 correct bits. Such an accuracy (with a minimal hardware cost, a single FP multiplier) is sufficient for many practical applications, e.g. accelerators for neural network tasks, power electronics, machine learning, computer vision and intelligent robotic systems [1, 34, 42]. From our research, we know that for two segments, we can obtain 7 correct bits, for four subsegments, 8.6 correct bits, and for eight subsegments, 10 correct bits of the result. In order to increase the accuracy of the approximation, we can increase the number of subsegments. For instance, 32 subsegments achieves 14-bit accuracy, 64 achieves 16-bit, 128, 18-bit, 256, 20-bit, 512, 22-bit, and 1024, 24-bit accuracy. This approach can be adapted to different formats with small mantissa lengths (equally fast algorithms for the square root but with lower

accuracy are described in [23]): bfloat, 7 bits, half, 10 bits. The disadvantage of this approach is the size of the look-up table to store the values of k0[\ ] and R[\ ] , especially for devices with limited memory resources such as microcontrollers, for which another type of algorithm must be implemented.

In this case, when using single precision, there is no need to change the value of the coefficient 0.5 in the Heron formula. However, due to their complexity and considerable duration, the division operations should be as a rule avoided when implementing square root algorithms on FPGAs. In this case, we used the above mentioned multiplication-based Newton–Raphson formula (2) [1, 24, 26, 31, 34, 36, 38, 42] for the inverse square root, which does not contain division operations.

Algorithm 8 Sqrt_13-bits. 

const float k0[2] = {0.88601269f, 1.25302145f} ;
const float k1[2] = {0.103027083f, 0.291411832f} ;
const int R[2] = {0x5f99e8b6, 0x5f59e8b6} ;
float Sqrt_13bits(float x)
{
  float y, c ;
  { int i = *(int*) & x ;
    int j = (i & 0x00800000) >> 23 ;
    i = R[j] - (i >> 1) ;
    y = *(float*) & i ;
    c = x * y ;
    y = c * (k0[j] - k1[j] * c * y) ;
    return y ; }
}

Algorithm 9 Sqrt_15-bits. 

float Sqrt_15-bits(float x)
{
  int i = *(int*) & x ;
  i = 0x5f1110a0 - (i >> 1) ;
  float y = *(float*) & i ;
  float c = x * y ;
  float d = c * y ;
  y = c * (2.2825186f - d * (2.2533049f - d)) ;
  return y ; }

Algorithm 10 Sqrt_23-bits. 

float Sqrt_23-bits(float x)
{
  union { float f; uint32_t u; } y = {x}, yy = {x} ;
  y.u = 0x5f1110a0 - (y.u >> 1) ;
  float c = x * y.f * y.f ;
  y.f = y.f * (2.2825186f - c * (2.2533049f - c)) ;
  yy.u = y.u - 0x00800000 ;
  y.f = x * y.f ;
  y.f = y.f + (x - y.f * y.f) * yy.f ;
  return y.f ; }

7 Conclusions

In this paper, a new approach to the application of Newton–Raphson (Heron) formula for computing square roots has been proposed. In particular, the use of magic constants is recommended for finding the initial approximation for Heron iterations. Such a technique ensures the fast creation of sufficiently accurate initial values for the computation of the square root due to a partitioning of range of arguments into segments, which are further partitioned into an uneven number of subsegments. In addition, we have proposed a modification of the Heron formula in a way that reduces the errors of the approximation after each iteration, at the cost of only two additional instructions: one multiplication and one conditional instruction if-else . We have also proposed simple modifications to the Newton–Raphson formula and the magic number method suitable for implementation on platforms with limited hardware resources, such as microcontrollers, FPGAs etc.
